# Contributing

This repository is a research archive as well as a codebase. Small, auditable
changes are preferred.

For a new experiment, add an experiment card before running it. Record the
question, fixed variables, data and model provenance, primary metrics, stop
rule, and claim ceiling. Keep exploratory analysis separate from a
pre-specified decision.

For a code change, include a short reproduction command and run the narrowest
applicable checks. Do not commit credentials, raw audio, feature tensors,
checkpoints, or generated caches. Do not turn a diagnostic observation into a
method claim without a controlled comparison and an explicit interpretation
boundary.
