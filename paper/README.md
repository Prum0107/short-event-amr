# Paper and experiment archive

This directory keeps the working manuscript, the R0–R31 timeline, the
continuously appended experiment report, and compact result tables. Generated
PDFs, slide decks, rendered previews, and raw review audio are not included in
this public release.

The manuscript is a working research document, not a claim that all archived
method variants are current or publication-ready. For the current decision
state, use the audit bundles and roadmap first.
