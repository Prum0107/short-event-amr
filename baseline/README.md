# Official QD-DETR baseline

This directory contains the recovered baseline source, configuration, and
dependency list used by the short-event diagnostics. It intentionally excludes
the trained checkpoint, feature tensors, raw audio, and dataset metadata.

The source is retained with its upstream license and citation in
`official_qd_detr/LICENSE` and `official_qd_detr/README.md`. The exact local
baseline commit and artifact hashes used in the audits are recorded in
[`../docs/provenance.md`](../docs/provenance.md).
